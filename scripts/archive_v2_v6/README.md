# V2-V6 Script Archive

This directory contains historical Movie3R scripts from the ShotToken / background AnchorToken / RICH anchor investigation phase.

These scripts are kept for reproducibility and review, but they are not the current V8 direction.

Archived categories:

- ShotToken and token-flow analysis.
- Background anchor matching and anchor-cache generation.
- RICH / AvatarReX AABB anchor-token diagnostics.
- V4-V6 training command wrappers.
- Token-only matching and hand-crafted anchor correction experiments.

Current V8 work should start from `docs/movie3r/v8/START_HERE.md` rather than extending these scripts by default.

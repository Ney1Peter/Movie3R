# Harmony4D 三视角、两次跳变原始帧

- 原始数据：`Harmony4D.zip`
- Split / sequence：`test/01_hugging`
- Capture：`002_hugging`
- 原始帧率：20 FPS
- 人数：2
- 相机顺序：`cam07 -> cam20 -> cam09`
- 两次相邻视角跳变：149.85°、169.86°

## 选择依据

正式 Harmony4D 测试结果中，单次大角度切镜案例
`h4d_test_01_hugging_002_hugging_extreme_cam07_cam20_b00151`
是 BRIDGE3R 在 extreme 案例中综合表现最好的案例：IDF1=1、Coverage=1、
W-MPJPE 203.81 mm、WA-MPJPE 128.42 mm、PA-MPJPE 57.33 mm、
ATE-Sim3 0.01894 m。`cam07 -> cam20` 的官方标定旋转跨度为 149.85°。

九帧素材保留这个正式单次切镜，并从同一 capture 的其余相机中加入 `cam09`。
在人物标定投影完整的候选中，`cam20 -> cam09` 提供 169.86° 的第二次大角度
跳变；`cam09` 在标定审计帧中对两个人的最小可见顶点比例为 1.0。
`cam07` 的最后一帧 00150 与 `cam20` 的第一帧 00151 正好对应正式实验的
相邻时间边界。

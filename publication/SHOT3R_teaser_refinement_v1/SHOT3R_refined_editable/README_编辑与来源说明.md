## 点云与人物的渲染

场景深度反投影后，使用方法自身相机放入同一世界坐标。人体掩码扩张 5 像素后用于排除人体区域点云；置信度阈值为 1.0。约 70.6 万个候选背景点经过剖切、范围裁剪与 0.024 单位的体素采样，最终显示 130,985 个真实预测点。每个体素保留已有点，不生成或填补新几何。

剖切视图移除近处遮挡人物的墙体和过远点，色彩统一混入 22% 白色以减轻背景干扰。显示分辨率为 2612×862，点大小为 2.4 像素。所有坐标经过同一个 180° 旋转以适配向上的渲染坐标约定。

人体使用原预测顶点与三角形连接，不修补身体、不改关节姿态、不移动单个人物、不插值或制造运动。历史透明效果属于展示方式；同一颜色的多个轮廓代表不同时间。

## 可编辑范围

PPT 的标题、文字、相机符号、箭头、形状仍为原生对象。原有中部组现包含 13 个独立渲染图层：1 层背景和 3 人×4 时刻的人体层。打开 PowerPoint 的“选择窗格”，进入 `03 Reconstruction` 组即可分别开关、替换或调整图层。移动其中一层会改变与背景的空间对应；需要改变三维观察视角时建议整体重新渲染。

SVG 同样保留文字、矢量标记和独立内嵌图片。照片与三维渲染是位图，不是可逐顶点编辑的二维矢量图。

需要修改三维视角或重新着色时，可使用：

- `geometry/four_times_native_meshes.glb`：12 个带身份/时刻名称的真实人体对象，可用 Blender 等三维软件打开。
- `geometry/four_times_native_meshes.npz`：四时刻、三个人的原生顶点与拓扑。
- `geometry/predicted_background_native.ply`：置信度与人体掩码筛选后、尚未剖切与采样的背景点。
- `geometry/displayed_background_native.ply`：最终被选中显示的点，在原生世界坐标中保存。
- `render_settings.json`：相机、显示坐标旋转、体素、透明度和颜色参数。

服务器生成脚本位于本包上级目录 `refine_teaser.py`。本包另附脚本副本用于查阅，其默认输入指向服务器保留的推理缓存；在其他机器重新执行时需要替换这些路径。直接编辑 PPT、SVG 或 GLB 不依赖服务器。

# SHOT3R 可编辑 Teaser

## 文件性质

这是“可编辑矢量标注 + 独立位图素材”的混合文件，不是全矢量三维场景，也不是将整张 PNG 放入 PPT 后冒充可编辑文件。

- `SHOT3R_editable.pptx`：一页 PowerPoint。含 23 个原生文本框、59 个原生图形/线条、17 个独立图片对象；按内容组织为命名组合。
- `SHOT3R_layered.svg`：独立 SVG 文件。文字保留为 `<text>`，图形保留为矢量路径/线条，照片和重建图层以图片形式内嵌，不依赖外部图片路径。
- `SHOT3R_preview.png`：仅用于预览，不是可编辑文件。
- `assets/`：九张原始帧裁图、点云背景、积木渲染、三色人物动作组，以及合并的重建素材。

## 哪些内容可编辑

标题、所有文字、Shot 标签、容器边框、CUT 箭头、三个相机符号、角度文字、世界坐标轴、底部圆点与输出框，均为原生可编辑对象。

九张视频帧是独立图片，可以替换、移动、缩放和裁剪。上方三张大图各使用用户提供的九宫格中对应行的第 2 帧；底部每个 Shot 使用对应行的第 1、2、3 帧，保持原顺序。照片没有重新生成。

中间点云背景、积木和紫色/红色/蓝色三组人体动作分别保存为透明 PNG。每组可作为一个图片对象移动、缩放或替换，但人物关节、单个重叠时间步和点云点不是可编辑的矢量或三维对象。

## PowerPoint 编辑

打开 PPTX，在“开始 → 选择 → 选择窗格”中定位命名组合：

1. `01 Header`：标题及徽标。
2. `02 Top shots`：上方照片、标签和 CUT。
3. `03 Reconstruction`：点云、积木和三色人物动作图片。
4. `04 World-frame labels`：说明文字、三个相机、角度和坐标轴。
5. `05 Online multi-shot stream`：底部时间轴及输出框。

选中组合后再次选中其中对象，或取消组合，即可分别编辑。照片可右键“更改图片”；替换后必要时调整裁剪。文字使用 Arial / Arial Narrow；不同电脑缺少相应字体时可能出现替代字体和轻微排版差异。

## SVG 编辑

文字、路径和图片均为分组对象。使用支持 SVG 对象编辑的软件打开文件后，进入对应组即可编辑。SVG 中的位图内嵌不意味着位图本身变成了矢量。文字没有转轮廓，便于直接修改内容。

## 重建图层的边界

中间的三维展示从本次对话已经生成的 teaser 中提取，保留现有的示意效果；没有从真实点云或 SMPL 数据重新渲染。最终论文应使用作者实际重建结果替换这一组图片。

图层拆分只提取现有图像中可见的像素，不恢复人体背后原本被遮挡的场景；移动人物组后不会自动补齐背后的点云。三色人物组并非逐帧完整人体资产，不能单独更改某一帧的关节姿态。修改动作或视角需要原始三维资产或新的渲染图。

## 画布

画布比例为 1672 : 941，PowerPoint 页面尺寸为 16.72 × 9.41 英寸。照片和渲染的实际清晰度仍受原始素材分辨率限制；矢量文字和图形不受这一限制。

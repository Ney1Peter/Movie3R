# v030 Main-Paper Outline and Evidence Budget

The main paper is fixed to nine pages before the non-paper statements and
references. Each section has one scientific role; complete protocol detail and
secondary tables remain in the supplement.

| Section | Role | Evidence retained in the main paper |
|---|---|---|
| Abstract | Define the same-scene cut problem, the causal operation, and the bounded empirical conclusion | EgoBody headline numbers and the dataset-equal viewpoint interaction |
| Introduction | Motivate recurrent-state failure and state the camera--human scope | Three-dataset macro and three contribution bullets |
| Related Work | Distinguish stateful reconstruction, global human reconstruction, human--scene methods, and association | Protocol-level positioning only; no pseudo-leaderboard |
| Method | Specify the causal information set and the complete reported method | read-only learned gauge, clean-reset recurrence, prediction-only association, shared translation, transformation scope |
| Experiments | Present the primary paired evidence and its limits | 129/90/88 protocols, viewpoint interaction, association denominators, detector stress failure |
| Discussion | Interpret gauge correction and disclose trade-offs | 2.79% updated parameters, limited runtime measurement, Harmony4D/AIST++/multi-cut failures |
| Conclusion | State the supported claim and scope boundary | causal camera--human bridging, not arbitrary editing or dense scene reconstruction |

The main paper deliberately does not contain the full external-method tables,
single-person AIST++ tables, development-only coefficient sensitivity, or
same-checkpoint token masking. Those records are useful for transparency but
are not the strongest matched-protocol evidence.

\subsection{Traditional Geometric Registration Controls}
\label{app:registration-controls}

% 中文：本节检验独立重建每个镜头后进行显式几何拟合，是否可以替代 Shot3R 的在线状态转移。
% R0 使用公开 Human3R 权重分别重建两个镜头；R1/R2 在边界处只使用预测的人体对应，R3 使用两个完整镜头的场景点云。
We test whether explicit geometric fitting between independently reconstructed
shots can substitute for the online state transition in \method{}. The R0
control reconstructs both shots independently with the public \humanthree{}
checkpoint. R1 matches predicted boundary people and estimates one
coordinate-wise median pelvis translation. R2 uses the same prediction-only
matching, followed by RANSAC and weighted Kabsch fitting over stable predicted
body joints~\citep{fischler1981ransac,kabsch1976solution}. R3 performs offline
FPFH mutual matching and global RANSAC on the two complete shot point clouds,
followed by point-to-plane ICP~\citep{rusu2009fpfh,besl1992registration}. In
each case, one shared transform is applied to all cameras, people, meshes, and
scene points after the transition.

% 中文：传统方法获得标注边界。每个数据集只在完整 Development split 上选择一组参数，经过一次 Holdout gate 后冻结；
% Test 不调参、不使用真实配准、不逐例选方法。拟合失败严格回退 R0 并保留在固定分母中。
All geometric controls receive annotated shot boundaries, whereas \method{}
uses its online detector. A single dataset-level setting for each control is
selected on the complete Development split, passed once through a disjoint
Holdout gate, and then frozen. Test data are never used for tuning, ground-truth
registration, or per-case method selection. Every failed fit is an exact R0
fallback and remains in the fixed denominator. Table~\ref{tab:supp-registration-full}
reports the complete aggregate results.

% 中文：平移不足以处理视角旋转，场景 ICP 的相机对齐也不保证人体位置正确。人体关节 SE(3) 很强，
% 但 Shot3R 在两个完整测试集上仍取得最低 W/WA/ATE 和最高 IDF1；这里只声称整体均衡结果，不声称所有差值显著。
Pelvis translation is insufficient under large viewpoint rotation. Scene

\subsection{EgoBody}
\label{app:egobody-details}

% 中文：正文已报告 EgoBody 的总体结果和主要机制分析。这里补充对齐—状态传播受控实验的局部与边界指标、
% Human3R—Shot3R 配对置信区间、跨镜头连续性以及不同视角范围下的结果。
The main paper reports the overall EgoBody results and principal mechanism
comparison. Here we provide local and boundary measures for the controlled
alignment--state-propagation comparison, paired confidence intervals, cross-shot
continuity, and viewpoint-stratified results.

% 中文：两个已对齐设置使用相同 checkpoint、标注边界和历史条件对齐，关闭显式人物关联与共享平移，
% 并仅改变对齐后传播的状态。表中相同的首帧相机误差确认了边界对齐关系保持不变。
% 局部人体误差几乎不变；重新初始化状态降低首帧根节点误差，而继续状态降低后续根节点误差。
The two aligned controls use the same checkpoint, annotated boundary, and
history-conditioned alignment, disable explicit association and shared
translation, and differ only in the state propagated afterward. Their equal
first-post camera errors verify that the boundary alignment is held fixed.
Local human accuracy is nearly unchanged; reinitialization lowers the
first-post root error, whereas continuation lowers the subsequent root error.

\subsubsection{Recurrent-state carry-over}
\label{app:egohumans-state-isolation}

% 中文：仅比较完整序列与状态重置后的世界坐标误差，无法区分“失去镜头间固定坐标联系”和
% “上一镜头状态改变新镜头内部轨迹”这两种影响。为单独检验后者，我们使用固定的 EgoHumans 90 样例协议，
% 对同一个原版 Human3R 权重进行状态隔离实验。Continuous 设置依次处理两个镜头并在边界延续状态；
% Reinitialized 设置从初始状态处理完全相同的后半段 50 帧。两者使用相同 RGB 和预处理，不启用 Shot3R 模块。
World-frame reconstruction error alone cannot distinguish losing a fixed
inter-shot coordinate relation from changing the trajectory within the new
shot. We isolate the latter on a fixed 90-case EgoHumans protocol using the
same original \humanthree{} checkpoint. The continuous setting processes both
shots in order and carries state across the transition; the reinitialized
setting processes the identical 50 frames after the transition from the initial state.
Both use the same preprocessing, and no \method{} module is enabled.

% 中文：EgoHumans 的每个镜头均由静态相机拍摄，因此第二镜头内的真实相对相机运动为单位变换。
% 对第一个切换后预测进行锚定后，我们计算后续帧相对于它的平移和旋转漂移。任意固定的镜头间世界坐标变换
% 会在该相对变换中抵消，因此该指标不会把状态重置后缺少跨镜头坐标联系误判为镜头内误差。
Each EgoHumans shot is recorded by a static camera, so the ground-truth
relative camera motion within the second shot is the identity. We anchor the
first prediction after the transition and measure
\begin{equation}
 \begin{aligned}
  \Delta\hat C_k&=\hat C_{B0}^{-1}\hat C_{Bk},\\
  d_T(k)&=\left\|\operatorname{trans}(\Delta\hat C_k)\right\|_2,\\
  d_R(k)&=\cos^{-1}\!\left(
  \frac{\operatorname{tr}(\operatorname{Rot}(\Delta\hat C_k))-1}{2}\right).
 \end{aligned}
 \label{eq:state-isolation-drift}
\end{equation}
Any fixed world-frame transform between shots cancels in this relative pose,
so the measure does not penalize reinitialization for lacking the inter-shot
coordinate relation. We average offsets $k=1,\ldots,16$ within each case,
then average cases within a capture and give all 27 captures equal weight.

  \centering
  % 中文图注：固定 EgoHumans 90 样例协议上的递归状态延续隔离实验。相同原版 Human3R 权重对完全相同的
  % 切换后 RGB 帧延续上一镜头状态或重新初始化状态。数值为锚定切换后首帧后，后续 16 帧的
  % 平均镜头内相机漂移，并对 27 个采集序列等权汇总。
  \caption{Isolating recurrent-state carry-over on the fixed 90-case
  EgoHumans protocol. The same original Human3R checkpoint processes identical
  frames after the transition with the preceding-shot state or a reinitialized
  state. We report mean within-shot
  camera drift over the next 16 frames after anchoring the first pose,
  with equal weight for each of 27 captures.}
  \label{tab:egohumans-state-isolation}
  \supptablesize
  \input{artifacts/egohumans_state_isolation/state_isolation_compact}
\end{table*}

% 中文：延续旧状态时，平均平移/旋转漂移为 1.124 米/14.58 度；重新初始化后为 0.026 米/0.20 度。
% 重新初始化在全部 27 个采集序列的两项指标上都更低。配对均值差及 95% bootstrap 区间分别为
% 1.098 [0.832, 1.372] 米和 14.38 [8.92, 20.49] 度；单侧配对 Wilcoxon 检验均为 p=7.45×10^-9。
As Table~\ref{tab:egohumans-state-isolation} shows, continued state produces
1.124\,m/$14.58^\circ$ mean translation/rotation drift, compared with
0.026\,m/$0.20^\circ$ after reinitialization. Reinitialization is lower on all
27 captures for both measures. The capture-paired mean reductions and 95\%
bootstrap intervals are 1.098 [0.832, 1.372]\,m and
$14.38^\circ$ [$8.92^\circ$, $20.49^\circ$]; both one-sided paired Wilcoxon
tests give $p=7.45\!\times\!10^{-9}$.

% 中文：结论对窗口长度稳定。对后续 10/32/49 帧，延续与重置的平移漂移分别为
% 1.045/0.019、1.256/0.039 和 1.387/0.047 米；旋转漂移分别为
% 14.34/0.16、15.12/0.27 和 15.65/0.34 度。四个预定义视角区间也具有相同排序。
The conclusion is stable to the measurement window. For windows of 10/32/49 frames,
continued versus reinitialized translation drift is
1.045/0.019, 1.256/0.039, and 1.387/0.047\,m; rotation drift is
$14.34^\circ$/$0.16^\circ$, $15.12^\circ$/$0.27^\circ$, and
$15.65^\circ$/$0.34^\circ$. The ordering is also unchanged in all four fixed
viewpoint strata. This control does not claim that reinitialization alone
solves multi-shot reconstruction---it loses the inter-shot coordinate relation.
Instead, it shows that the preceding-shot state causes time-varying error
within the subsequent shot, supporting separate treatment of alignment and
recurrent-state propagation.

% 中文：消融结果再次表明，只重置状态会破坏世界坐标联系；相机对齐恢复相机关系，
% 而完整方法进一步利用人物关联和共享变换改善人体轨迹与身份连续性。
The ablation in Table~\ref{tab:egohumans-system} confirms the same pattern as
EgoBody. Reinitialization alone breaks world-frame continuity; camera
alignment restores the inter-shot camera relation, while the full method also
uses person association and the shared transform to improve human trajectories
and identity continuity.

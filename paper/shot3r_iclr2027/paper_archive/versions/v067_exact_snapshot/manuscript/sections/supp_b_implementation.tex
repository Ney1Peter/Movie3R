\section{Training and Implementation Details}
\label{app:implementation}

% 中文段落标题：训练配置。
% 中文：论文报告的 Shot3R 模型直接从预训练 Human3R 初始化，并在 AvatarReX 的 lbn1/zzr 人物序列与 THuman00/02 上训练。
% 每个来源包含 8,000 个镜头跳变序列和 2,000 个连续镜头序列。镜头跳变样本依次取 A(t)、A(t+1)、
% B(t+2)、B(t+3)，连续样本则取同一相机的四个连续帧；两类样本均带有统一世界坐标系中的相机和人体标注。
\paragraph{Training configuration.}
The reported \method{} model is initialized directly from pretrained
\humanthree{} and trained on the lbn1/zzr subjects of AvatarReX and
THuman00/02. Each source contains 8,000 shot-transition clips and 2,000
continuous clips. A shot-transition clip follows
$A(t),A(t+1),B(t+2),B(t+3)$, whereas a continuous clip contains four consecutive frames
from one camera; both carry camera and human annotations in a shared world
frame.

% 中文：图像编码器、递归解码器、点图头、基础相机/人体预测头和 Multi-HMR 主干均被冻结。
% 可训练的镜头对齐模块包括 14.39M 的三 token 对齐块、1.78M 的相机潜变量残差头、2.96M 的人体潜变量残差头，
% 以及 0.50M 的秩 8 相机/人体预测头 LoRA，共 19.62M 个参数，占完整模型 1.63%。
The image encoder, recurrent decoder, point-map head, base camera and human heads,
and Multi-HMR backbone~\citep{baradel2024multihmr} are frozen. The trainable
shot-alignment module comprises a 14.39M alignment block with three typed
tokens, a 1.78M camera latent-residual head, a 2.96M human latent-residual head, and 0.50M
rank-8 LoRA parameters in the camera and human heads~\citep{hu2022lora}: 19.62M parameters
in total, or 1.63\% of the 1.208B-parameter model. The three alignment tokens
occupy the 768-dimensional decoder space, and the alignment gate is shared
with the human residual branch.

% 中文：每轮进行 100 次更新，每个批次包含 10 个四帧序列；AvatarReX 与 THuman 的采样概率为 0.6 和 0.4。
% 训练共 72 轮、7,200 次优化器更新。AdamW 使用 beta=(0.9,0.95)、权重衰减 0.05、四轮线性预热至 2e-4，
% 随后余弦衰减至 1e-6，并启用自动混合精度和梯度检查点。
Each epoch contains 100 updates with ten four-frame sequences per batch;
AvatarReX and THuman are sampled with probabilities 0.6 and 0.4. Training runs
for 72 epochs and 7,200 optimizer updates. AdamW uses
$\beta=(0.9,0.95)$, weight decay 0.05, four-epoch linear warm-up to
$2\!\times\!10^{-4}$, and cosine decay to $10^{-6}$, with automatic mixed
precision and gradient checkpointing.

% 中文：相机平移、旋转和人体平移分别由 Smooth-L1、四元数测地线距离和 Smooth-L1 监督。
% 对齐门控目标来自以 0.5 米和 45 度归一化并截断的未校正相机误差，改进项要求校正误差小于未校正误差，
% 两个正则项约束相机和人体潜变量残差的大小。
Let $e$ and $e^{\mathrm{raw}}$ be the corrected and uncorrected camera errors after
normalizing translation by $0.5$\,m and rotation by $45^\circ$. We optimize the
shot-alignment module with
\begin{equation}
  \begin{split}
  \mathcal L_{\mathrm{align}}={}&\mathcal L_t+5\mathcal L_R
  +0.05\operatorname{BCE}\!\left(g,
  \operatorname{clip}(e^{\mathrm{raw}},0,1)\right)\\
  &+0.05[e-e^{\mathrm{raw}}]_+
  +10^{-5}\mathcal R_{\mathrm{cam}}
  +10\mathcal L_h+10^{-5}\mathcal R_{\mathrm{human}},
  \end{split}
  \label{eq:supp-alignment-objective}
\end{equation}
where $\mathcal L_t$ and $\mathcal L_h$ are Smooth-L1 camera and human
translation losses, $\mathcal L_R$ is quaternion geodesic distance, $g$ is
the learned alignment gate, and the residual terms constrain the camera and
human latent updates. Camera and human supervision is evaluated across the
four-frame training sequence; no ground truth is used at inference.

% 图中训练曲线为每轮目标的全局均值，验证曲线为四个划分中位数损失的均值。星号标记所有实验使用的第 72 轮检查点。

\paragraph{Shot-transition detection.}
% 中文：检测器从连续RGB帧对计算20维颜色、灰度、哈希、边缘、光流、直方图和ORB统计，并维护最近三个帧对的历史。
% 单层GRU使用32维隐藏状态与线性二分类头；以BCE和AdamW训练120轮，学习率与权重衰减分别为2e-3和2e-3，判定阈值为0.5。
% 正式双镜头协议中，第一个超过阈值的预测触发状态转换；检测器不访问未来帧、相机标定、人体标注或身份。
The detector computes 20-dimensional colour, grayscale, hash, edge, optical-flow,
histogram, and ORB statistics from consecutive RGB frames and retains the most
recent three frame pairs. A single-layer GRU~\citep{cho2014gru} with a
32-dimensional hidden state and a linear binary head predicts the transition
probability. It is trained for 120 epochs using binary cross-entropy and AdamW
with a learning rate of $2\!\times\!10^{-3}$ and weight decay of
$2\!\times\!10^{-3}$ (seed 20260805). The decision threshold is 0.5. The
frozen training ledger contains 408 frame pairs (216
positive) from eight constructed patterns spanning AvatarReX, THuman, and two
MVHuman transition settings. In the formal two-shot protocol, the first score
above threshold triggers the state change. No future frames, camera calibration,
body annotations, or person identities enter the detector.

% 中文：三个主协议的首次触发均与标注边界一致；Harmony4D在13200帧中没有边界外阳性响应。
The first trigger coincides with the annotated boundary in all 129 EgoBody,
90 EgoHumans, and 88 Harmony4D streams. Harmony4D has no off-boundary positive
response across 13,200 scored frames.

\paragraph{Full-system runtime.}
% 中文：完整系统效率表在五段固定的 150 帧 Harmony4D 多镜头输入上报告七种方法的墙钟时间。
% 五段输入在汇总时间前固定，包含 hugging、grappling2、sword2、mma4 和 mma5；每段由两个连续出现的
% 75 帧单目镜头组成。每个必要预测阶段均使用单张 NVIDIA L20；计时包含各阶段的新进程启动和模型加载，
% 直到原生预测写盘。对于官方实现拆分出的多个必要阶段，报告其阶段时间之和。
Table~\ref{tab:end-to-end-runtime} reports full-system wall time for seven
methods on five fixed 150-frame Harmony4D multi-shot streams. The set was frozen
before runtime aggregation and contains hugging, grappling2, sword2, mma4, and
mma5; each input comprises two sequential 75-frame monocular shots. Every
required prediction stage uses one NVIDIA L20, and timing includes its fresh
process launch and model loading through native prediction serialization. For
releases with multiple required stages, we sum their stage times.

% 中文：计时包含模型构建与权重加载，以及发布流程所需的检测、分割、跟踪、相机恢复、时序/全局优化和人体恢复；
% PromptHMR 和 TRACE 的保留运行还包含逐样本的轻量硬链接输入整理，但不进行图像解码或重新编码。
% 数据下载与数据集解压、评测、论文格式转换和渲染不计入。FPS 使用五段共 750 帧除以总墙钟时间计算，
% 秒数报告五段视频的均值和总体标准差。全部 35 次运行均成功，失败不会被静默剔除。
The scope includes model construction and checkpoint loading, plus any
detection, segmentation, tracking, camera recovery, temporal/global
optimization, and human recovery required by the released prediction path.
The retained PromptHMR and TRACE runs also include lightweight per-case
hardlink staging, without image decoding or re-encoding. Dataset download and
archive extraction, metric evaluation, paper-format conversion, and rendering
are excluded. FPS is the micro-average $750/\sum_i t_i$; seconds report the
mean and population standard deviation across the five clips. All 35 method--clip
runs completed successfully; a failed run would not have been silently omitted.

\paragraph{Transition-count control.}
To isolate the number of shot boundaries, we duplicate one fixed 150-frame
EgoBody RGB input to form the same 300-output-frame timeline for every
configuration and place 0, 1, 3, or 5 annotated transitions. Each boundary
requires one additional evaluation of its boundary frame, so $C$ transitions
execute exactly $300+C$ neural frames. Hardware, precision, and timing scope
match the controlled reconstruction test above; each configuration has one
warm-up followed by three measured repetitions, from which we report the
median.

Median time spans 102.6--107.3\,s and does not increase monotonically with the
number of transitions; peak allocation does not increase either. Thus, within
this test range, up to five boundary operations do not produce a throughput
change distinguishable from the measured execution variation. Because more
transitions also split inference into shorter segments, the lower peaks must
not be interpreted as constant full-system memory for arbitrarily long
sequences.

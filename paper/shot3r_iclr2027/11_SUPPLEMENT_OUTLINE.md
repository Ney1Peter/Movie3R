# v030 Supplement Outline

The supplement is compiled in the same PDF and continues the main-paper table
and figure counters.

| Letter | Section | Purpose |
|---|---|---|
| A | Complete Evaluation Protocol | case construction, fixed denominators, evaluator-only information, metrics, aggregation, external interfaces |
| B | Learned Module and Implementation | training schedule, parameter accounting, loss weights, data disjointness, detector and runtime boundaries |
| C | Additional Method Details | tokens, association, coordinate convention, fallback, and repeated cuts |
| D | Complete Quantitative Results | full viewpoint, detector, AIST++, EgoBody, EgoHumans, and Harmony4D records |
| E | Held-Out MVHuman Weak-Texture Stress Audit | geometric stress results, detector early-trigger failure, and released-method availability |
| F | Component Scope and Additional Evidence | what each retained diagnostic can and cannot establish |
| G | Visualisation Convention | provenance and method-native rendering boundaries |
| H | Limitations and Scope | association, detector, translation, scene, backbone, runtime, and data limits |
| I | Literature--Protocol Context | access/interface comparison without mixing incompatible numbers |
| J | Evidence Boundaries | claim-to-evidence restrictions and deferred studies |
| K | Data Governance and Disclosure | licences, privacy, assistance, and release limits |

The ordering prioritizes reproducibility before exhaustive numerical tables and
places failure audits beside, rather than outside, the positive evidence.

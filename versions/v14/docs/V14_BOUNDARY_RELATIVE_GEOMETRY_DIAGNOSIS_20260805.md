# V14 shot 边界相机—人体相对几何诊断（2026-08-05）

## 结论先行

用户指出的几何约束是正确的：如果 post shot 通过一个世界坐标刚体变换
`G` 被放到 pre 坐标系，那么必须同时更新

```text
C_post' = G C_post
X_human' = G X_human
```

深度点云也应通过更新后的相机 pose 进入同一个世界坐标。只修改人体而保持
相机不变，会改变相机—人体相对位置，因此视觉上必然产生不应有的空隙。

## 当前差距来自哪里

AvatarReX `lbn1` 两帧实验（pre index 4、post index 5）中，使用当前
`B0+BRTC+C1` payload 得到：

| 量 | pre | post | 解释 |
|---|---:|---:|---|
| 人体 root 的 GT 误差 | 约 0.640 m | 约 0.066 m | BRTC 只修正了 post；pre 人体仍有深度偏差 |
| root 世界坐标 z | 2.515 m | 1.870 m | 造成约 0.65 m 的人体空隙 |
| post B0 相机误差 | - | 1.697 m / 66.51° | 低纹理下 B0 相机仍错误 |

因此，当前最终联合版本虽然把 post 相机修到了约 `0.011 m / 0.40°`，并把
post 人体修到约 `0.100 m` MPVPE，但它没有回溯修正 pre 人体。看到的空隙主要
是 pre 预测的错误，不能简单把 post 人体硬拉回 pre，否则会重新引入约 64 cm
的绝对人体误差。

## 三个版本的含义

### 1. 8137/8138：人体-only 诊断版

它们使用

```text
C_post' = C_post
X_post' = root + R (X_post - root)
```

这是为了孤立观察人体方向残差，不是最终流程。它违反了相机—人体相对几何
不变约束，不能作为最终 demo 或论文主线。

### 2. `avatarrex_human_joint_a1.0`：共享 SE(3) 可视化基线

该版本用人体对应点估计 post 到 pre 的共享刚体变换，并同步作用于 post
相机和人体。两帧 root seam 约 3 cm，满足“人体贴在一起”；相机也确实随
人体移动，相对关系保持不变。它的缺点是 pre 人体本身错误，所以共享变换
会把 post 绝对位置一起拉错，首帧相机平移误差约 1.08 m、人体 root 误差约
0.64 m。

可视化端口：`8139`（CPU）。

### 3. 当前联合相机—人体版本

它使用 BRTC root 作为绝对位置锚点，再用人体方向和 root ray 联合更新 post
相机与人体。它在 GT 绝对误差上明显更好，但因为 pre 人体没有被回溯修正，
在世界视图中仍可能看到 pre/post root 间的空隙。

## 下一步正确问题

不能在“强行让人体贴 pre”和“保持 post 绝对 root 正确”之间凭主观选择。
下一版应做**双侧、置信度加权的 shot-boundary 优化**：

1. 以最后一个 pre 和第一个 post 的相机—人体对作为观测；
2. 估计一个共享 SE(3)，始终同步更新相机、深度点云和人体；
3. 对 pre/post 人体 root 分别使用 BRTC/root-ray 置信度；
4. pre 人体置信度低时，不强制把 post 拉向错误的 pre root；
5. 首个 post 到达后允许一次有界的 pre 边界回溯修正，随后 shot 内冻结并
   因果更新。

这才同时满足：相机要动、人体要贴、相机—人体相对位置不能被破坏，并且不
   用 GT 参与推理。
